### intro

This project built a hardware-based Network-on-Chip (NoC) prototype in **SystemVerilog**, verified through simulation using **VCS**. Operating entirely at RTL, the system implements a packet-switched routing network with distributed nodes and multi-port routers, transferring packets between multiple concurrent hardware components.

### network architecture

To enable communication between independent components, the topology uses two central routers and six terminal nodes. Packets inject into nodes as 32-bit words containing source, destination, and payload data.

Each router consists of four `RouterCorner` modules. When a corner receives a packet, it checks the destination address via a `PortChecker`, routing it to the appropriate output corner. If a packet's destination node resides on the opposite router, it forwards across a dedicated bridge link between the two routers.

### packet serialization

To transmit data efficiently over narrow channels without requiring wide buses, nodes serialize 32-bit packets into 8-bit bytes before sending them to the router. Communication uses a strict handshake protocol (`free_outbound`/`put_outbound`) to prevent buffer overflows.

### priority arbitration

Port contention occurs when multiple input ports simultaneously request to route packets to the same output port.

To resolve conflicts and guarantee transaction fairness, we designed a Least-Recently Used (LRU) pointer-based priority arbiter (`Handler`). This arbiter tracks which ports have recently transmitted and dynamically shifts priority ordering. Under high-load stress testing, this round-robin mechanism prevented packet starvation, routing concurrent requests with a balanced distribution to maintain strict fairness.
