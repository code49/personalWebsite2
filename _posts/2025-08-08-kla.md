KLA builds the optical inspection and metrology tools chip fabs rely on to catch sub-micron manufacturing flaws. During wafer fabrication, high-speed optical systems scan silicon wafers and [photomasks](https://en.wikipedia.org/wiki/Photomask), capturing image data at hundreds of gigabytes per wafer. Their solutions broadly fall under three areas:

- Inspection: Optical and electron-beam tools that scan wafers and photomasks for flaws.
- Metrology: High-precision sensors that measure feature dimensions, layer thickness, and pattern alignment.
- Data Analytics: Software that analyzes defect maps to pinpoint manufacturing issues in real time.

I worked in KLA's Broadband Plasma (BBP) division, which develops brightfield optical inspection systems. These tools scan wafers using light wavelengths ranging from visible to deep ultraviolet (DUV). Electron-beam tools offer higher spatial resolution but are far too slow for high-volume manufacturing; brightfield optical inspection bridges that gap, balancing sub-resolution image fidelity with high wafer throughput.

_Read more about KLA's BBP tools in [this article](https://www.kla.com/advance/innovation/klas-legacy-of-broadband-plasma-products-lights-the-way-for-future-innovations)._

### my work

At production speeds (processing hundreds of wafers per hour), raw image data transfer becomes a severe system bottleneck. To process data at line speed without slowing down inspection, we offloaded lossless image compression to a reconfigurable FPGA card.

<p align="center">
  <kbd>
    <img src="/assets/images/kla/jpeg-ls-pixels.png" alt="jpegls-pixels" 
    style="display: block; margin: 0 auto; border: 1px solid black;"/>
  </kbd>
  <br><i>Pixels A through D used to predict target pixel X in JPEG-LS.</i>
</p>

The pipeline uses the [JPEG-LS (lossless JPEG)](https://en.wikipedia.org/wiki/Lossless_JPEG) algorithm. A spatial predictor estimates incoming pixel $X$ using neighboring context ($A$, $B$, $C$), encoding only the residual difference between predicted and actual values. For uniform intensity regions common in photomask geometries, run-length mode collapses identical pixel runs to maximize compression ratios while guaranteeing bit-exact data recovery.

<p align="center">
  <kbd>
    <img src="/assets/images/kla/alveo.png" alt="alveo-u50" 
    style="display: block; margin: 0 auto; border: 1px solid black;"/>
  </kbd>
  <br><i>AMD Alveo U50 FPGA accelerator card targeted for this design.</i>
</p>

I built and integrated a high-performance JPEG-LS decompression engine targeted for the AMD Alveo U50 FPGA card:

*   **Multi-Core Control Framework:** Architected system-level control logic to handle parallel data distribution and frame reconstruction across multiple decompression cores without dropping line synchronization.
*   **RTL Debug & Simulation:** Used Siemens Questa for SystemVerilog RTL simulation and AMD Vivado IP Integrator for hardware synthesis, resolving core-interface timing issues and frame-stitching boundary bugs.
*   **Hardware Validation:** Optimized resource utilization on the Alveo U50 and verified end-to-end pipeline throughput on KLA's hardware-in-the-loop benchmarks.
