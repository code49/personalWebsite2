### intro

This project designed a synthesizable USB 2.0 Host Serial Interface Engine (SIE) in **SystemVerilog**, verified in simulation using **VCS**. Working entirely at RTL, the host implements a multi-threaded architecture that interfaces with an encrypted thumb drive model. The engine manages physical-layer signaling, NRZI clock extraction, transaction error recovery, and memory paging.

### bit-level engine

The physical-layer engine translates differential bus signals (`DP` and `DM`) into clean data packets. On the transmit path, the bitstream passes through:
1. **CRC Generators:** Computes 5-bit CRCs for token packets and 16-bit CRCs for data packets.
2. **Bit Stuffer:** Inserts a zero-bit after detecting six consecutive ones to prevent receiver clock drift.
3. **NRZI Encoder:** Toggles output states on zeros and maintains states on ones, using tri-state bus drivers for single-ended zero (SE0) sequences.

The receive path mirrors this flow through an NRZI decoder, bit unstuffer, and parallel CRC checker.

### protocol handler

Operating above the serial bitstream, the protocol handler converts high-level read/write commands into standard USB packet sequences (**OUT**, **IN**, **DATA0**, **ACK**, **NAK**).

<p align="center">
  <kbd>
    <img src="/assets/images/usb/custom_types.png" alt="Custom SV Types" 
    style="display: block; margin: 0 auto; border: 1px solid black; max-width: 85%;" />
  </kbd>
  <br><i>Custom SystemVerilog packet and transaction struct definitions.</i>
</p>

To handle physical bus noise and missing responses, the protocol handler uses a robust error-recovery FSM:
*   **Timeout Detection:** Uses an 8-bit timer to detect device silence, declaring a timeout if the device fails to respond within 255 clock cycles.
*   **NAK & Retry Arbitration:** If a packet is corrupted (violating CRC residues) or times out, the host returns a NAK and retries the transaction up to 7 times before aborting.

### verification & simulation

The host was verified in simulation using VCS against edge-case test suites:
*   **Edge Data Patterns:** Maximum bit-stuffing transitions and boundary-value CRC calculations.
*   **Stress Cycles:** 100 random sequential reads and writes to verify address paging logic and FSM stability.
*   **Fault Injection:** Synthetic packet corruptions, timeouts, and abort scenarios to confirm error recovery up to the 7-retry limit.
