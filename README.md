Welcome to the repository for my personal website, hosted live at **[davidlechan.dev](https://davidlechan.dev)**. 

This website serves as my digital portfolio, blog, and professional profile. Built using **[Jekyll](https://jekyllrb.com/)** and the elegant, flat-styled **[Yat theme](https://github.com/jeffreytse/jekyll-theme-yat/)**, it showcases my resume, personal projects, contact information, and archives in a responsive interface with full dark mode support. The project is deployed automatically to GitHub Pages using GitHub Actions.
