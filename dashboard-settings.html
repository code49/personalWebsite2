cloudflare calendar worker setup guide ▾

Google Calendar, Apple iCloud, and Outlook block browser requests (CORS). Deploy a free Cloudflare Worker to proxy calendar feeds securely:

  1. Log in to workers.cloudflare.com and choose Workers & Pages > Create Application > Create Worker.
  2. Name your worker (e.g. calendar-worker) and click Deploy.
  3. Click Edit Code and replace the code with the script below:
export default {
  async fetch(request) {
    const url = new URL(request.url);
    const targetUrl = url.searchParams.get('url');
    if (!targetUrl) {
      return new Response('Missing ?url= parameter', { status: 400 });
    }

    const corsHeaders = {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Methods': 'GET, OPTIONS',
      'Access-Control-Allow-Headers': '*',
    };

    if (request.method === 'OPTIONS') {
      return new Response(null, { headers: corsHeaders });
    }

    try {
      const res = await fetch(targetUrl, {
        headers: { 'User-Agent': 'Mozilla/5.0 (compatible; CalendarWorker/1.0)' },
      });
      const body = await res.text();
      return new Response(body, {
        status: res.status,
        headers: {
          ...corsHeaders,
          'Content-Type': 'text/calendar; charset=utf-8',
          'Cache-Control': 'public, max-age=300',
        },
      });
    } catch (err) {
      return new Response('Proxy Error: ' + err.message, {
        status: 502,
        headers: corsHeaders,
      });
    }
  },
};
  1. Click Deploy.
  2. Copy your worker URL (e.g. https://calendar-worker.<subdomain>.workers.dev/?url=) into the input above and click Save Settings.
